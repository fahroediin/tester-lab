Coba Sekarang Lihat Fitur
Fitur

Semua yang Anda butuhkan untuk otomasi test

6-Tier Scoring deterministik

Pencocokan elemen non-LLM: Test ID, Label, ARIA Role, Text, Placeholder, Fuzzy. Hasil selalu konsisten.

Multi-framework

Satu skenario jadi Playwright TS/JS, Cypress, Selenium Python, atau Robot Framework.

10 tipe aksi

fill, click, select, check, uncheck, upload, wait, dan tiga jenis assertion.

Dry-run dan self-healing

Validasi headless, auto-healing ke kandidat berikutnya bila selector gagal.

Scenario Builder

Buat skenario visual atau import JSON/YAML, edit kode inline lalu jalankan.

Interaction Recorder

Rekam klik dan isian di situs target. Mendukung SSO, OutSystems, Next.js.

Folder tree per proyek

Test case dipisah per proyek. Kelompokkan, filter, pindah, dan kelola dari Flow History.

Terminal Runner dan video

Jalankan script langsung, mode headless atau headed dengan perekaman video.

Keamanan enterprise

Dual auth dan RBAC, API key ter-hash, code sanitizer, SSRF guard, storage privat, RLS.

Pengujian lebih cepat, hasil yang bisa dibuktikan

Buat test tanpa kode, jalankan langsung, simpan riwayatnya. Deterministik dan tanpa vendor lock-in.
